MY LIFE DASHBOARD — START HERE
===============================
Website: https://serakib.github.io/my-life-dashboard/

Laptop:
- Chrome বা Edge-এ Website খোলো।
- চাইলে browser menu থেকে Install app / Create shortcut ব্যবহার করতে পারো (browser support অনুযায়ী)।
- একই browser profile ব্যবহার করো, কারণ data browser-এর Local Storage-এ থাকে।

প্রথমবার setup:
- My Routine-এ নিজের বাস্তব সময় অনুযায়ী routine edit/add করো।
- Checklist-এ আজকের ৩টি priority যোগ করো।
- Settings-এ নাম ও weekly study goal ঠিক করো।
- Study Planner-এ session log এবং subject progress update করো।
- নিয়মিত JSON backup download করো।

Feature:
Overview: আজকের summary।
My Routine: সময়, কাজ ও category অনুযায়ী routine।
Checklist: daily task add, complete, edit, delete; অসম্পূর্ণ কাজ পরের দিনে নেওয়া।
Study Planner: subject log, study history, focus/break timer ও subject progress।
Progress: মোট logged study, active day, ৭ দিনের chart ও weekly review।
Screen Time: Dashboard active time auto; অন্য app-এর সময় manual।
Daily Learning: ছোট learning lesson ও নিজের note।
Life Guide: daily revision ও problem-solving framework।
Settings: profile, goals, backup, restore, reset।

Data ও privacy:
- কোনো login/cloud sync নেই। Data এই browser-এর Local Storage-এ থাকে।
- Browser data clear করলে বা অন্য computer/browser-এ গেলে data হারাতে পারো।
- নিয়মিত JSON backup download করে নিরাপদ জায়গায় রাখো।
- Restore করলে বর্তমান data replace হবে।
- Screen Time Windows-এর সব app scan করে না; শুধু এই Dashboard-এর visible/focused সময় auto track করে।

GitHub Pages:
Repository: https://github.com/serakib/my-life-dashboard
Settings → Pages → Deploy from a branch → main → /(root) → Save.
Deployment সম্পন্ন হলে উপরের Website URL খুলবে।

Troubleshooting:
- পুরোনো version দেখালে Ctrl+F5 দিয়ে hard refresh করো।
- data দেখা না গেলে একই browser/profile ব্যবহার করছ কি না দেখো।
- সমস্যা থাকলে আগে backup নাও; তারপর browser console error পরীক্ষা করো।
