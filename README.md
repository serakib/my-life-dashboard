# My Routine Manager

A minimal personal daily checklist for study, classes, prayer, health and personal tasks.

## Features
- Daily checklist with simple completion ticks
- Editable recurring routine and times
- One-day extra tasks
- Previous-day checklist history
- LocalStorage persistence (no account, server or cloud sync)
- JSON backup and restore
- Responsive layout for mobile and desktop
- No streaks, points, leaderboards, timers, feeds or gamification

## Use
Open `index.html` in a modern browser, or enable GitHub Pages for this repository. Your data stays in that browser's LocalStorage. Download a JSON backup occasionally if you want to protect it from browser-data clearing.

## Privacy
The app does not send routine data to a server. Clearing browser site data may erase the saved routine, so keep a backup if the data matters.
